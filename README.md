## 🛠️ Project Details

### 1️⃣ ML-struc | Master Workflow Blueprint
* **Objective:** Standardized template created to streamline project creation and avoid starting from scratch.
* **Key Features:** Boilerplate pipeline for Data Preprocessing, Feature Scaling, Model Selection, and Visualizations.

---

### 2️⃣ ML-pro.1 | Foundational Analysis (Student Data)
* **Focus:** Data exploration, handling missing values, basic regression analysis, and evaluation metrics.
* **Tech Stack:** Python, Pandas, Scikit-learn.

---

### 3️⃣ ML-pro.2 | Real Estate Price Regression
* **Focus:** Machine Learning evaluation dynamics & critical analysis.
* **Key Learning:** Implemented `LinearRegression` and `RandomForestRegressor` with `StandardScaler`. Analyzed why model architecture alone cannot overcome uncorrelated feature noise, emphasizing **Data Quality over Algorithm Complexity**.

---

### 4️⃣ ML-pro.3 | End-to-End Customer Churn Prediction Engine
* **Focus:** Advanced classification, EDA, feature encoding, and interactive testing.
* **Highlights:**
  * **Dataset:** Telco Customer Churn (~7,043 records, 21 feature columns).
  * **Model Performance:** Achieved **~79.8% Accuracy** using `RandomForestClassifier`.
  * **Exploratory Data Analysis (EDA):** Custom Matplotlib plots (Bar distribution, Scatter plot of Tenure vs Monthly Charges, Histogram distribution).
  * **Interactive Inference Engine:** Built a custom `live_customer_prediction()` function to deliver real-time predictions with confidence scores for new customer inputs.
